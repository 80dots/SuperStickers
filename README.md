# Super Stickers

바탕화면에 스티커 메모를 붙이는 Windows 데스크톱 애플리케이션입니다.
C++/Win32 네이티브 셸 + WebView2 하이브리드 구조로, 가볍고 빠르게 동작하면서도
서식 있는 텍스트·이미지·동영상·YouTube 임베드까지 지원합니다.

![아이콘](src/icons/app.ico)

## 주요 기능

- **6가지 메모 종류** (`+` 메뉴 / 트레이에서 선택):
  - **일반 메모**: 서식 있는 텍스트(굵게·목록·체크리스트) + 이미지·동영상·YouTube 임베드
  - **마크다운 메모**: 편집(Text) ↔ 보기(View) 전환, GFM 지원. 편집 중 `<` 입력 시
    마크다운 태그 목록이 설명과 함께 인텔리센스로 표시되어 선택 삽입 가능
  - **파일 메모**: 간단한 파일 브라우저 — 탐색기에서 파일/폴더 드래그앤드롭 또는 추가 버튼,
    목록/썸네일(작게)/썸네일(크게) 보기, 선택 후 클립보드 복사(탐색기 붙여넣기 가능),
    더블클릭 실행
  - **웹 메모**: URL을 등록하면 스티커 안에서 웹사이트를 직접 표시·클릭 탐색.
    처음 등록한 URL(홈)과 마지막으로 본 페이지로 이동 가능, 마지막 페이지 자동 복원
  - **PDF 메모**: PDF 파일을 등록(선택 또는 드래그앤드롭)하면 내장 뷰어로 내용 표시
  - **그룹**: 아래 메모 그룹 참조
- **스티커 메모**: 프레임리스 스티커 창, 드래그 이동/크기 조절, 항상 위 고정(핀)
- **색상**: 20가지 프리셋 + 컬러 휠(RGB 자유 선택). 선택한 색은 테마와 무관하게 그대로
  유지되며, 배경 밝기에 따라 글자색이 자동 조정됨
- **리치 에디터**: 굵게·기울임·밑줄·취소선, 글머리/번호 목록, 체크리스트,
  **들여쓰기·내어쓰기**, 이미지 붙여넣기·드래그 앤 드롭, 동영상 삽입,
  YouTube URL 붙여넣기 → 즉시 임베드 재생
- **형광펜**: 서식 툴바의 형광펜 버튼으로 선택한 글에 배경색 적용 — 프리셋 8색 +
  **직접 색 추가**(SV 사각형·Hue 슬라이더·HEX 입력, 최대 24색). 추가한 색은 **모든
  메모창이 함께 공유**하고, 어두운 색을 칠하면 글자색이 자동으로 밝아짐. 지우기 제공.
  **일반·마크다운 메모 모두** 지원 (마크다운은 `<mark>`로 저장되어 다른 편집기에서도 열림)
- **텍스트 선택 메뉴**: 메모에서 글을 선택하면 선택 영역 옆에 메뉴가 뜸 —
  위쪽에 **서식 격자**(굵게·기울임·밑줄·취소선·형광펜·목록·체크리스트·들여쓰기),
  아래에 **AI 동작**(요약 / 맞춤법 검사 / 문장 다듬기 / AI에게 물어보기). 선택한 전문이
  문맥으로 전달되며, 결과의 삽입·교체·복사는 AI 패널 그대로 사용
- **툴바 '더보기'**: 창이 좁아지면 헤더와 서식 툴바의 버튼이 뒤쪽부터 `⋯` 메뉴로 접힘
  (닫기·미리보기·AI는 항상 남음)
- **마크다운 모드**: 스티커별로 마크다운 입력 모드 전환(타이틀바 `M↓` 버튼),
  편집 ↔ 미리보기 토글. GFM 지원(체크리스트·표·코드 블록), 미리보기에서 체크박스를 클릭하면
  소스의 `[ ]`/`[x]`가 동기화되고, YouTube 링크는 임베드로 렌더링.
  **서식 툴바와 선택 메뉴는 일반 메모와 같은 항목을 제공**한다 — 굵게·기울임·밑줄·취소선·
  형광펜·목록·체크리스트·들여쓰기·이미지·동영상이 모두 마크다운 원본으로 들어간다
  (들여쓰기는 줄 앞 공백 2칸, Tab/Shift+Tab과 동일). 본문이 HTML이 아니라 원본 텍스트라
  **3D 모델 임베드만 일반 메모 전용**이다
- **메모 그룹**: 타이틀·삭제 버튼이 있는 헤더를 가진 그룹 박스. 스티커/그룹의 `+` 메뉴 또는
  트레이에서 그룹 생성, **메모 창을 그룹 위로 드래그해서 놓으면 그룹에 추가**(드래그 중
  하이라이트 표시), 반대로 **카드를 그룹 창 밖으로 드래그하면 그 지점에 개별 스티커로 분리**
  (다른 그룹 위에 놓으면 그 그룹으로 이동). 그룹 헤더의 `+`로 그룹 안에 바로 새 메모 생성.
  그룹 안에서는 카드 드래그로 순서 변경, 인라인 편집, 분리(팝아웃), 삭제 가능. 정렬은
  **균일 그리드** / **내용 길이별 혼합(masonry)** / **목록** 세 방식 전환. 그리드는
  모든 카드가 같은 크기(**작음/중간/크게 S/M/L** 3단계 전체 조정), 혼합(masonry)에서만
  **카드 하단 핸들을 드래그해 메모별 높이를 개별 조절**(더블클릭으로 기본 복원) 가능.
  목록은 **메모의 타이틀만 한 줄로 표시**(타이틀이 없으면 본문 미리보기 한 줄). **배경색(20 프리셋 + RGB
  컬러 휠)과 배경 투명도(0~100%)** 조정 가능 — 투명도는 그룹 배경에만 적용되어 뒤의
  바탕화면·창이 실제로 비쳐 보이고, 헤더와 메모 카드는 항상 선명하게 유지(0%면 배경이
  완전히 사라져 카드만 떠 있는 모양). 그룹 삭제 시 멤버 메모는 삭제되지 않고 개별
  스티커로 분리
- **휴지통**: 메모 삭제 시 즉시 지우지 않고 휴지통으로 이동(모든 삭제는 네이티브 확인
  팝업을 거침). 보관 기간(기본 30일, 일 단위 설정, 자동 삭제하지 않음 옵션)이 지난 항목은
  자동으로 완전 삭제. 관리자 창의 **휴지통 탭**에서 삭제된 메모를 미리보기로 확인하고
  **복원**(개별 스티커로 되살림)하거나 개별 **완전 삭제** 가능. 설정과 트레이 메뉴의
  **휴지통 비우기**(최종 확인 팝업 포함) 제공. 휴지통 사용을 끄면 삭제 시 바로 완전 삭제
- **시스템 트레이 상주**: 창을 닫아도 트레이에 유지. 트레이 메뉴에서
  새 스티커 / 모든 스티커 감추기·보이기 / 스티커 목록 / 설정 / **정보** / 휴지통 비우기 / 종료
- **자동 시작**: Windows 시작 시 자동 실행 (설정 또는 설치 시 선택)
- **다중 선택**: Shift+클릭으로 여러 메모창을 고르고(다시 Shift+클릭하면 해제), 하나를
  끌면 선택한 창이 배치를 유지한 채 함께 이동. Delete를 누르면 모두 숨김. 선택하지 않은
  곳을 클릭하면 해제
- **창 자석 정렬**: 메모창을 다른 메모창 근처로 끌면 정해진 간격으로 붙고 위/아래·좌/우
  가장자리가 자동으로 맞춰짐. **테두리를 끌어 크기를 바꿀 때도** 잡고 있는 변이 이웃 창의
  변에 맞춰짐. 붙는 간격과 민감도(상/중/하 — 높을수록 멀리서 붙음)를
  설정에서 조절 (설정에서 On/Off, 기본 On·10px·중)
- **메모창 UI 자동 숨김**: 메모창을 클릭하면 헤더·서식 툴바가 나타나고, 마우스가 벗어나고
  3초 뒤 사라져 내용만 남음 — **창 크기는 그대로 두고** 본문이 그 여백을 채우며,
  페이드 아웃 → 재배치 → 페이드 인 순서라 글자가 튀어 보이지 않음. 입력 중이거나 AI
  응답을 받는 중에는 유지되고 그룹창은 해당 없음 (설정에서 On/Off, 기본 On). 하위 옵션 **'클릭할 때만 UI 보이기'**(기본 On)를
  끄면 마우스를 올리기만 해도 UI가 나타남
- **테마**: 라이트 / 다크 / 시스템 설정 따름 (OS 테마 변경 즉시 반영). 테마는 관리자
  창(목록·설정)에만 적용되고, **메모창과 그룹창은 스티커 색 기반으로 항상 동일하게 표시**
- **UI 크기**: 30%~200% 배율 선택 — DPI가 바뀌는 것처럼 모든 창의 모든 요소(메모 본문
  포함)가 일괄 확대/축소되고 **창 크기도 함께 조정**됨 (화면 밖으로 나가면 자동 보정,
  즉시 반영·재시작 후 유지)
- **다국어**: 한국어 / 영어 (실행 중 전환 가능, 최초 실행 시 OS 언어 자동 감지)
- **3D 모델 임베드**: 일반 메모의 툴바 3D 버튼 또는 드래그앤드롭으로 GLB·GLTF·OBJ·STL
  모델을 본문에 삽입 — **원본 파일을 복사 없이 직접 참조**해 렌더링(원본이 갱신되면
  다시 열 때 반영, 원본이 없어지면 로드 실패 표시). 뷰어에서 좌드래그 Orbit /
  **우드래그 줌**(위로 확대·아래로 축소) / 가운데 버튼 Pan — 휠은 메모 본문 스크롤에
  쓰이도록 비워 둠. Open 버튼으로 원본 위치 열기, 우상단 휴지통으로 제거.
  렌더 영역 아래 **View Mode**(Wireframe / Solid / PBR) 전환, PBR에서는 **Skybox IBL**을
  3종 HDRI 중 선택 가능(선택 상태는 메모에 저장). `.gltf`는 같은 폴더의 .bin·텍스처까지
  함께 로드 (three.js·HDRI 로컬 번들, 오프라인 동작)
- **태그**: 메모(일반·마크다운)마다 태그를 추가/삭제 — 서식 툴바 바로 위의 태그바에서
  Enter로 추가(쉼표로 여러 개), ✕로 삭제. **태그 이름을 누르면 본문에서 그 낱말을 찾아
  이동**(누를 때마다 다음, 끝에서 처음으로 순환)
- **AI Review**: 메모에 새 내용이 입력되면 타이틀바의 AI Review 버튼이 활성화(강조 표시).
  실행하면 내용을 **한국어로 번역·요약해 메모 상단에 표시**하고, **중요 키워드를 태그로
  자동 추가**하며, 요약을 바탕으로 **제목을 생성해 타이틀바에 표시**(연필 버튼으로 수정
  가능). **한↔영 번역도 동시에 수행**되어, 완료 후 메모 최상단의 **한국어/English 선택**으로
  제목·요약·본문 전체를 선택한 언어로 표시(원문 언어 선택 시 편집 뷰, 반대 언어 선택 시
  번역 뷰). 모두 로컬 Ollama로 처리
- **AI 백엔드 선택**: 관리자 창 **AI 탭**에서 **자체 모델**과 **Ollama** 중 고릅니다.
  - **자체 모델**: Ollama를 설치하지 않고 앱이 직접 모델을 돌립니다. 실행 엔진(llama.cpp의
    `llama-server`, CPU 17MB / Vulkan 33MB)과 모델을 한 번 내려받으면 그다음부터는 오프라인에서
    동작합니다. 모델은 1.0GB~4.7GB 다섯 가지(Qwen3 1.7B/4B/8B, EXAONE 3.5 2.4B, Qwen2.5 7B)를
    Hugging Face에서 받아 쓰며, 각 모델의 라이선스를 화면에 표시합니다. GPU가 있으면 Vulkan
    가속을 씁니다.
  - **Ollama**: 기존 방식 그대로 — 로컬 Ollama 서버에 연결해 씁니다.
- **Local AI**: 메모 요약, 맞춤법 검사, 문장 다듬기, 번역(한↔영),
  자유 질문/생성 — 어느 백엔드든 모두 로컬에서 실행되어 데이터가 외부로 나가지 않습니다.
  스트리밍 표시·중단 지원. 연결·모델 설정은 관리자 창의 **AI 탭**에 있으며,
  모델 선택 아래 **접이식 다운로드 섹션**(기본 접힘, 연결 실패 시 자동 펼침) 제공:
  **Ollama 다운로드**(설치 여부 확인 후 공식 설치 프로그램을 진행률 표시와 함께 내려받아
  무인 설치, 완료 시 네트워크 노출 옵션 자동 설정 — 실패 시 수동 안내)와
  **모델 다운로드**(엄선된 추천 모델 콤보박스에서 선택, 진행률 바·취소 지원).
  완료 시 모델 목록이 자동 갱신됩니다.
- **AI 프롬프트 편집**: 관리자 창 **AI 탭**에서 작업별(AI 리뷰·요약·맞춤법 검사·문장
  다듬기·번역·질문) 지시문을 직접 수정 — 비워 두면 기본값으로 되돌아가고, 변경은 열려
  있는 모든 메모창에 즉시 반영됩니다.
- **데이터 관리**: 관리자 창의 데이터 탭에서 저장 폴더 바로 열기, **저장 경로 변경**
  (선택한 폴더로 데이터 복사 후 앱 재시작 — 원본은 보존), **백업 ZIP 만들기**(전체 데이터를
  선택한 폴더에 압축 저장) 제공
- **정보 탭**: 관리자 창의 **정보** 탭(트레이 메뉴 '정보…'로 바로 이동)에서 버전·릴리스 날짜·
  라이선스·저작권, 운영체제·WebView2 런타임·실행 파일·데이터 폴더 같은 시스템 정보,
  개인정보 처리 방침 요약, MIT 라이선스 전문, 포함된 오픈소스 고지, 저장소·릴리스·버그 신고
  링크를 확인할 수 있습니다. **정보 복사** 버튼으로 버그 신고에 붙일 환경 정보를 한 번에 복사
- **자동 저장**: 입력 후 0.8초 디바운스 자동 저장, 원자적 파일 쓰기(.bak 백업)로 데이터 보호
- **단일 인스턴스**: 중복 실행 시 기존 인스턴스의 스티커를 표시

## 시스템 요구 사항

- Windows 10/11 (x64)
- [Microsoft Edge WebView2 런타임](https://developer.microsoft.com/microsoft-edge/webview2/)
  — Windows 11에는 기본 내장. 없으면 설치 프로그램이 자동으로 설치합니다.
- (선택) AI 기능 사용 시 [Ollama](https://ollama.com) — `ollama pull llama3` 등으로 모델 준비

## 설치

`installer/Output/SuperSticker-Setup-<버전>.exe`를 실행합니다.

> 버전을 올릴 때는 `CMakeLists.txt`의 `project(SuperSticker VERSION ...)`과
> `SS_RELEASE_DATE`만 고치면 됩니다 — exe 버전 리소스, 앱의 정보 탭, 설치 파일 이름이
> 모두 여기서 나옵니다.
한국어/영어 설치 UI를 제공하며, 관리자 권한 없이 사용자 단위로 설치됩니다
(`%LOCALAPPDATA%\Programs\Super Stickers`).

제거 시 스티커 데이터(`%APPDATA%\SuperSticker`)는 보존됩니다.

## 사용법

| 동작 | 방법 |
|---|---|
| 새 스티커 | 트레이 우클릭 → 새 스티커, 또는 스티커 타이틀바 `+` → 새 메모 |
| 새 그룹 | 트레이 우클릭 → 새 그룹, 또는 스티커 타이틀바 `+` → 새 그룹 |
| 그룹에 메모 추가 | 메모 창을 그룹 창 위로 드래그해서 놓기, 또는 그룹 헤더 `+` → 새 메모 |
| 그룹 내 정렬 | 그룹 헤더의 그리드/혼합 아이콘, 카드 상단 바 드래그로 순서 변경 |
| 그룹에서 분리 | 카드 상단 바를 그룹 창 밖으로 드래그, 또는 `⇱` 버튼 |
| 그룹 색·투명도 | 그룹 헤더의 색상 점 → 프리셋/컬러 휠/투명도 슬라이더 |
| 이동 | 타이틀바 드래그 |
| 크기 조절 | 창 가장자리 드래그 |
| 색상 변경 | 타이틀바 왼쪽 색상 점 클릭 → 프리셋 20색 또는 사용자 지정(컬러 휠) |
| 마크다운 모드 | 타이틀바 `M↓` 버튼으로 전환, 툴바 오른쪽 버튼으로 편집↔미리보기 |
| 항상 위 | 핀 버튼 |
| 닫기(숨김) | `×` 버튼 — 종료가 아니라 트레이로 숨김 |
| 전체 감추기/보이기 | 트레이 아이콘 더블클릭 또는 트레이 메뉴 |
| YouTube 삽입 | 유튜브 URL을 복사해 에디터에 붙여넣기 |
| AI 도우미 | 서식 툴바 맨 오른쪽 `AI` 버튼 → 요약/맞춤법 검사/문장 다듬기/번역/질문 |
| 완전 종료 | 트레이 우클릭 → 종료 |

### Ollama 연동

1. [Ollama](https://ollama.com)를 설치하고 실행합니다 (`ollama serve`).
2. 트레이 → 설정 → Ollama 섹션에서 엔드포인트(`http://localhost:11434`) 확인 후
   **연결 테스트**를 누릅니다.
3. 모델을 선택하면 스티커의 AI 패널에서 요약·다듬기·번역·질문 기능을 사용할 수 있습니다.

## 빌드

### 요구 도구

- Visual Studio 2026 (Community 이상, C++ 데스크톱 워크로드) — 번들 CMake/Ninja 사용
- 설치 프로그램 생성 시: Inno Setup 6 (`winget install JRSoftware.InnoSetup`)
- 의존성(WebView2 SDK, WIL, nlohmann/json)은 CMake FetchContent가 자동 다운로드합니다.

### 빌드 명령

```powershell
# Release 빌드
.\scripts\build.ps1

# Release 빌드 + 설치 프로그램 생성
.\scripts\build.ps1 -Installer
```

산출물:

- 실행 파일: `build\release\SuperSticker.exe` (+ `ui\` 폴더)
- 설치 프로그램: `installer\Output\SuperSticker-Setup-<버전>.exe`

## 데이터 저장 위치

```
%APPDATA%\SuperSticker\
├─ settings.json              # 테마, 언어, 자동 시작, Ollama 설정
├─ stickers\<uuid>\           # 메모 1개 = 폴더 1개
│   ├─ memo.json             # 내용·위치·색상·소속 그룹 (.bak 백업 자동 생성)
│   ├─ Image\                # 삽입한 이미지
│   ├─ Video\                # 삽입한 동영상
│   ├─ PDF\                  # PDF 메모의 문서
│   └─ 3D\                   # 3D 임베드 썸네일
├─ groups\<uuid>.json         # 그룹별 타이틀·위치·정렬 방식·멤버 순서
└─ trash\<uuid>\             # 삭제된 메모 폴더 (구조 동일)
```

메모 폴더는 스티커 목록에서 **내보내기** 버튼으로 `.ssticker`(zip) 파일로 저장할 수 있고,
**스티커 가져오기** 버튼이나 목록으로 끌어다 놓기로 다시 불러올 수 있습니다
(가져온 메모에는 새 id가 부여됩니다).
