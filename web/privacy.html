개인정보처리방침Privacy Policy

최종 수정: 2026년 8월 27일 Last updated: 27 August 2026

Super Stickers는 사용자의 어떤 정보도 수집하거나 전송하지 않습니다. 앱에는 분석 도구나 사용 통계 기능이 들어 있지 않으며, 개발자가 운영하는 서버도 없습니다. Super Stickers does not collect or transmit any of your information. The app contains no analytics or usage-tracking code, and there is no server operated by the developer.

메모 데이터는 어디에 저장되나요Where your notes are stored

작성한 메모, 그룹, 첨부한 이미지·동영상, 설정값은 모두 사용자 PC의 %APPDATA%\SuperSticker 폴더에만 저장됩니다. 저장 위치는 앱의 설정에서 원하는 폴더로 변경할 수 있습니다. 클라우드 동기화 기능은 제공하지 않습니다. Your notes, groups, attached images and video, and settings are stored only in %APPDATA%\SuperSticker on your own PC. You can move this location in the app’s settings. There is no cloud sync.

앱을 제거해도 이 데이터는 삭제되지 않고 보존됩니다. 제거 과정에서 데이터 삭제 여부를 직접 선택할 수 있습니다. Uninstalling the app leaves this data in place; the uninstaller asks whether you want it removed.

AI 기능AI features

요약, 맞춤법 검사, 문장 다듬기, 번역, AI Review 등 모든 AI 기능은 사용자 PC에 설치된 Ollama에 http://localhost:11434로 요청을 보내 처리됩니다. 메모 내용이 인터넷으로 나가지 않으며, OpenAI를 비롯한 외부 AI 서비스를 사용하지 않습니다. Summarization, spellcheck, rewriting, translation and AI Review all run through Ollama installed on your own PC, via a request to http://localhost:11434. Note contents never leave your machine, and no third-party AI service such as OpenAI is used.

앱이 인터넷에 접속하는 경우When the app connects to the internet

다음은 모두 사용자가 직접 실행했을 때만 발생합니다. Each of the following happens only when you initiate it.

  • 웹 메모 — 사용자가 입력한 주소의 웹사이트에 직접 접속합니다. 이때 해당 웹사이트는 일반적인 브라우저 방문과 동일하게 사용자의 IP 주소와 쿠키를 처리할 수 있습니다. Web notes connect directly to the URL you enter. That site can see your IP address and set cookies exactly as it would in a normal browser visit.
  • YouTube 임베드 — youtube-nocookie.com의 개인정보 보호 강화 모드를 사용합니다. YouTube embeds use the privacy-enhanced youtube-nocookie.com domain.
  • Ollama 및 모델 다운로드 — 설정의 AI 탭에서 다운로드를 누르면 Ollama 공식 서버(ollama.com)에 접속합니다. Ollama and model downloads contact the official Ollama servers (ollama.com) when you start a download from the AI tab in settings.

앱은 자동 업데이트 확인을 수행하지 않습니다. 새 버전은 이 웹사이트나 GitHub 릴리스 페이지에서 직접 확인해 주세요. The app does not check for updates automatically. Please check this site or the GitHub releases page for new versions.

이 웹사이트This website

이 사이트는 Cloudflare Pages에서 제공되며, 방문자 분석 도구나 광고를 사용하지 않고 추적 쿠키도 설정하지 않습니다. 언어와 테마 선택은 브라우저의 로컬 저장소에만 보관되며 외부로 전송되지 않습니다. This site is served from Cloudflare Pages. It uses no visitor analytics or advertising and sets no tracking cookies. Your language and theme preferences are kept in your browser’s local storage and are never transmitted.

다운로드 버튼을 누르면 GitHub 릴리스에 보관된 파일로 이동합니다. 이 시점부터는 GitHub의 개인정보처리방침이 적용됩니다. 서비스 제공 과정에서 Cloudflare가 접속 로그를 처리할 수 있습니다. Download buttons redirect to files hosted on GitHub Releases, at which point GitHub’s privacy policy applies. Cloudflare may process access logs as part of serving this site.
