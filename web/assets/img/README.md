# 스크린샷 넣는 곳

아래 파일명 그대로 이 폴더에 넣으면 사이트에 자동으로 반영됩니다.
파일이 없으면 해당 자리는 점선 자리표시자로 표시되므로, 하나씩 채워 넣어도 됩니다.

| 파일명 | 위치 | 내용 | 권장 비율 |
|---|---|---|---|
| `hero.png` | 첫 화면 | 바탕화면에 여러 색 스티커가 예쁘게 배치된 전경 | 16:10 |
| `group.png` | 그룹 섹션 | 그룹 창 — masonry 정렬 + 배경 투명도 적용 | 4:3 ~ 16:10 |
| `markdown.png` | 마크다운 섹션 | 마크다운 메모 — 편집 화면과 미리보기 | 4:3 ~ 16:10 |
| `ai.png` | 로컬 AI 섹션 | AI 패널 — 요약·번역 결과가 보이는 상태 | 4:3 ~ 16:10 |
| `og.png` | SNS 공유 미리보기 | 로고 + 대표 화면 조합 | **1200×630 고정** |

## 촬영 요령

- 해상도 1920×1080 이상, PNG로 저장
- 라이트/다크 중 **한쪽으로 통일**
- 바탕화면에 개인 파일명·아이콘이 노출되지 않도록 정리
- 메모 내용은 실제로 쓸 법한 문장으로 채우기 (Lorem ipsum 금지)

## 용량 줄이기

PNG가 1MB를 넘으면 WebP로 변환하는 편이 좋습니다.
변환 후에는 `index.html`의 확장자도 함께 바꿔 주세요.

```bash
npx @squoosh/cli --webp auto web/assets/img/hero.png
```
