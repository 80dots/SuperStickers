메모 하나로 부족할 때, 여섯 가지 종류 Six kinds of notes

텍스트만 적는 메모가 아닙니다. 필요한 형태를 골라 바탕화면에 붙이세요. Not just text. Pick the format you need and stick it on your desktop.

📝

일반 메모Rich note

굵게·목록·체크리스트 같은 서식과 이미지·동영상·YouTube 임베드를 지원합니다. YouTube 주소를 붙여넣으면 바로 재생됩니다. Bold, lists and checklists, plus images, video and YouTube embeds. Paste a YouTube URL and it plays right away.

↓

마크다운 메모Markdown note

편집과 보기를 오가며 GFM으로 작성합니다. 미리보기의 체크박스를 클릭하면 원본 소스가 함께 갱신됩니다. Write in GFM and toggle between edit and preview. Ticking a checkbox in the preview updates the source too.

📁

파일 메모File note

탐색기에서 파일·폴더를 끌어다 놓으면 목록이나 썸네일로 보관됩니다. 더블클릭으로 실행하고, 복사해 탐색기에 붙여넣을 수 있습니다. Drop files and folders from Explorer to keep them as a list or thumbnails. Double-click to open, or copy and paste them back into Explorer.

🌐

웹 메모Web note

주소를 등록하면 스티커 안에서 웹사이트를 그대로 띄우고 클릭 탐색까지 됩니다. 마지막으로 본 페이지는 자동으로 복원됩니다. Register a URL and browse the site inside the sticker itself. The last page you viewed is restored automatically.

📄

PDF 메모PDF note

PDF를 끌어다 놓으면 내장 뷰어로 바로 열립니다. 자주 보는 문서를 바탕화면에 펼쳐 두세요. Drop in a PDF and it opens in the built-in viewer — keep the documents you reference most right on your desktop.

▦

그룹Group

흩어진 메모를 하나의 보드로 묶습니다. 창을 그룹 위로 끌어다 놓기만 하면 바로 정리됩니다. Collect scattered notes into a single board — just drag a window onto the group and drop it.

끌어다 놓으면 정리됩니다 Organize by dragging

메모 창을 그룹 위로 끌면 그룹에 들어가고, 카드를 밖으로 끌어내면 그 자리에 다시 개별 스티커가 됩니다. 폴더를 만들고 이름을 붙이는 과정이 없습니다. Drag a note window onto a group to file it away, or drag a card back out to turn it into a standalone sticker again. No folders to create, no names to type.

  • 세 가지 정렬Three layouts — 균일 그리드, 내용 길이별 혼합(masonry), 제목만 보는 목록 — uniform grid, masonry by content length, or a title-only list
  • 카드 크기 조절Resizable cards — 전체를 S/M/L로 바꾸거나, 혼합 모드에서 메모마다 높이를 따로 조절 — switch all cards to S/M/L, or set each note’s height in masonry mode
  • 배경 투명도Adjustable transparency — 0~100%로 조절하면 뒤의 바탕화면이 비쳐 보이고, 카드는 선명하게 유지됩니다 — from 0 to 100%; the desktop shows through while cards stay crisp
  • 안전한 삭제Safe deletion — 그룹을 지워도 안에 있던 메모는 개별 스티커로 남습니다 — deleting a group leaves its notes behind as individual stickers

마크다운으로 빠르게 Write in Markdown

편집 화면에서 <를 입력하면 마크다운 태그 목록이 설명과 함께 나타나 골라 넣을 수 있습니다. 체크리스트·표·코드 블록을 포함한 GFM을 지원하고, YouTube 링크는 임베드로 렌더링됩니다. Type < while editing to get an annotated list of Markdown tags to insert. Full GFM support including checklists, tables and code blocks — and YouTube links render as embeds.

  • 편집 ↔ 미리보기 즉시 전환Instant edit / preview toggle
  • 미리보기의 체크박스가 소스와 양방향 동기화Preview checkboxes sync back to the source
  • 메모마다 태그를 붙여 분류Tag notes to keep them sorted

🔒 전부 내 PC에서 처리 — 외부 전송 없음 🔒 Runs entirely on your PC — nothing is uploaded

로컬 AI가 읽고, 요약하고, 번역합니다 Local AI reads, summarizes and translates

Ollama와 연동해 메모 요약, 문장 다듬기, 한↔영 번역, 자유 질문을 지원합니다. 모델이 내 컴퓨터에서 돌기 때문에 메모 내용이 서버로 전송되지 않습니다. API 키도, 구독료도 필요 없습니다. Connect Ollama to summarize notes, polish sentences, translate between Korean and English, or just ask questions. The model runs on your machine, so note contents are never sent to a server. No API key, no subscription.

  • AI Review — 버튼 한 번으로 요약·제목 생성·키워드 태그 추가·한영 번역을 한꺼번에 — one click summarizes, titles, tags keywords and translates
  • 설치까지 앱 안에서Guided setup — 설정 화면에서 Ollama와 추천 모델을 진행률을 보며 바로 내려받습니다 — download Ollama and a recommended model from the settings screen, with progress shown
  • 스트리밍 출력Streaming output — 결과가 실시간으로 표시되고 언제든 중단할 수 있습니다 — results appear as they generate and can be stopped anytime

그 밖의 기능 Everything else

3D 모델 임베드3D model embeds

GLB·GLTF·OBJ·STL을 메모 안에서 회전·확대해 봅니다. 원본 파일을 복사하지 않고 직접 참조하며, 와이어프레임·솔리드·PBR 렌더링을 지원합니다. Orbit and zoom GLB, GLTF, OBJ and STL models inside a note. Files are referenced in place, with wireframe, solid and PBR rendering.

휴지통Recycle bin

삭제한 메모는 휴지통에 보관됩니다. 미리보기로 확인하고 되살리거나, 보관 기간이 지나면 자동으로 정리됩니다. Deleted notes go to a bin where you can preview and restore them. Items past the retention period clean themselves up.

테마와 UI 배율Theme & UI scale

라이트·다크·시스템 연동 테마를 지원하고, 모든 창을 30%~200%로 한 번에 확대·축소할 수 있습니다. Light, dark or follow-the-system themes, plus a 30–200% scale that resizes every window at once.

한국어 · EnglishKorean & English

실행 중에 전환할 수 있고, 처음 실행할 때는 OS 언어를 자동으로 감지합니다. Switch languages while running; on first launch the OS language is detected automatically.

데이터 관리Data management

저장 폴더를 원하는 위치로 옮기고, 전체 데이터를 ZIP으로 백업할 수 있습니다. Move the storage folder wherever you like, and back up everything to a ZIP.

안전한 자동 저장Safe autosave

입력이 멈추면 0.8초 뒤 자동 저장되며, 원자적 쓰기와 백업 파일로 데이터를 보호합니다. Saves 0.8 seconds after you stop typing, using atomic writes and backup files to protect your data.

트레이 상주 · 자동 시작Tray & autostart

창을 닫아도 트레이에 남고, Windows 시작 시 자동 실행할 수 있습니다. 모든 스티커를 한 번에 숨기거나 보이게 할 수도 있습니다. Closing a window keeps the app in the tray, and it can start with Windows. Hide or show every sticker at once.

UI 자동 숨김Auto-hiding chrome

마우스가 벗어나고 3초가 지나면 헤더와 툴바가 사라지고 내용만 남습니다. Three seconds after the pointer leaves, the header and toolbar fade away and only your content remains.
