칠하고, 고르고, 시키는 세 가지가 한 번에 좋아졌습니다. Three things got better at once: marking up, selecting, and asking.

프리셋 8색에 더해 직접 만든 색까지 칠합니다. 추가한 색은 모든 메모창이 함께 쓰고, 어두운 색을 칠하면 글자색이 자동으로 밝아집니다. Eight presets plus colors you mix yourself. New colors are shared across every note window, and text turns light automatically on dark shades.

글을 선택하면 그 자리에 서식 격자와 AI 동작이 함께 뜹니다. 툴바까지 마우스를 옮길 일이 없고, 서식은 이어서 여러 번 적용할 수 있습니다. Select text and a formatting grid appears right there, with AI actions below. No trip to the toolbar, and formats can be applied back to back.

태그로 본문 찾기Jump by tag

헤더와 툴바가 사라져도 창 크기는 그대로입니다. 본문이 그 여백을 채우고, 글자가 튀어 보이지 않게 페이드로 넘어갑니다. The window no longer shrinks: content fills the freed space, and the swap happens behind a fade so nothing jumps.

메모 종류Note types

텍스트만 적는 메모가 아닙니다 Not just a box for text

여섯 가지 중에 필요한 형태를 골라 바탕화면에 붙이세요. Pick one of six formats and stick it on your desktop.

📝

일반 메모Rich note

굵게·기울임·목록·체크리스트에 더해 형광펜과 들여쓰기까지. 이미지·동영상·YouTube 임베드를 붙이면 메모 안에서 바로 재생됩니다. Bold, italic, lists and checklists, plus a highlighter and indenting. Drop in images, video or a YouTube link and it plays inside the note.

↓

마크다운 메모Markdown note

편집과 보기를 오가며 GFM으로 씁니다. 미리보기에서 체크박스를 누르면 원본 소스가 함께 갱신되고, 선택 메뉴의 서식도 그대로 통합니다. Write GFM and toggle between edit and preview. Ticking a checkbox updates the source, and the selection menu formats the raw text for you.

📁

파일 메모File note

파일·폴더를 끌어다 놓고 목록이나 썸네일로 보관합니다. 더블클릭으로 실행, 복사해서 탐색기에 붙여넣기도 됩니다. Drop files and folders in as a list or thumbnails. Double-click to open, or copy them back into Explorer.

🌐

웹 메모Web note

주소를 등록하면 스티커 안에서 웹사이트를 그대로 띄웁니다. 마지막으로 본 페이지는 자동 복원됩니다. Register a URL and browse the site inside the sticker. The last page you viewed is restored automatically.

📄

PDF 메모PDF note

PDF를 끌어다 놓으면 내장 뷰어로 열립니다. 자주 보는 문서를 펼쳐 두세요. Drop in a PDF and it opens in the built-in viewer — keep your reference documents open.

▦

그룹Group

흩어진 메모를 하나의 보드로 묶습니다. 창을 그룹 위로 끌어다 놓기만 하면 정리되고, 카드를 밖으로 끌어내면 다시 개별 스티커가 됩니다. 그리드·혼합·목록 세 가지 정렬과 배경 투명도를 그룹마다 따로 정할 수 있습니다. Collect scattered notes into one board: drag a window onto the group to file it, drag a card out to set it free again. Each group keeps its own layout — grid, masonry or list — and its own background transparency.

정리Organizing

끌어다 놓으면 정리됩니다 Organize by dragging

메모 창을 그룹 위로 끌면 그룹에 들어가고, 카드를 밖으로 끌어내면 그 자리에서 다시 개별 스티커가 됩니다. 폴더를 만들고 이름을 붙이는 과정이 없습니다. Drag a note window onto a group to file it, or drag a card back out to turn it into a standalone sticker. No folders to create, no names to type.

  • ✓세 가지 정렬Three layouts — 균일 그리드, 내용 길이별 혼합(masonry), 제목만 보는 목록 — uniform grid, masonry by content length, or a title-only list
  • ✓카드 크기 조절Resizable cards — 전체를 S/M/L로 바꾸거나 혼합 모드에서 메모마다 따로 조절 — switch all cards to S/M/L, or size each note in masonry mode
  • ✓배경 투명도Adjustable transparency — 0~100%로 조절하면 바탕화면이 비쳐 보이고 카드는 선명하게 남습니다 — from 0 to 100%; the desktop shows through while cards stay crisp
  • ✓창 자석 정렬Window snapping — 창을 옮길 때도, 테두리를 끌어 크기를 바꿀 때도 이웃 창에 맞춰집니다 — windows align to each other when you move them and when you resize them

로컬 AILocal AI

읽고, 요약하고, 번역합니다 — 전부 내 PC에서 Reads, summarizes and translates — all on your PC

Ollama와 연동해 요약, 맞춤법 검사, 문장 다듬기, 한↔영 번역, 자유 질문을 지원합니다. 모델이 내 컴퓨터에서 돌기 때문에 메모가 서버로 전송되지 않습니다. API 키도, 구독료도 없습니다. Connect Ollama to summarize, check spelling, refine sentences, translate between Korean and English, or just ask. The model runs on your machine, so nothing is uploaded. No API key, no subscription.

  • ✓AI Review — 버튼 한 번으로 요약·제목 생성·태그 추가·한영 번역을 한꺼번에. 태그는 본문에 실제로 있는 낱말만 골라 붙습니다 — one click summarizes, titles, tags and translates. Tags are picked only from words that really appear in the note
  • ✓맞춤법 검사와 문장 다듬기Spellcheck vs. refine — 앞은 틀린 것만 고치고, 뒤는 뜻을 지킨 채 자연스럽게 고쳐 씁니다 — one fixes only what is wrong, the other rewrites for flow while keeping the meaning
  • ✓프롬프트 편집Editable prompts — 각 작업의 지시문을 설정에서 직접 고치고, 비우면 기본값으로 돌아갑니다 — rewrite the instruction behind each task; clear it to restore the default
